The ``5-text_indentation`` module
===================================

Import the function:

    >>> text_indentation = __import__('5-text_indentation').text_indentation

Two new lines are added after each '.', '?' and ':':

    >>> text_indentation("Hello. World? Bye: end")
    Hello.
    <BLANKLINE>
    World?
    <BLANKLINE>
    Bye:
    <BLANKLINE>
    end

Leading and trailing spaces around each line are removed:

    >>> text_indentation("  Leading spaces.  And : more.")
    Leading spaces.
    <BLANKLINE>
    And :
    <BLANKLINE>
    more.
    <BLANKLINE>

Text with no delimiter is printed as a single line:

    >>> text_indentation("No punctuation here")
    No punctuation here

An empty string prints nothing:

    >>> text_indentation("")

A non-string text raises a TypeError:

    >>> text_indentation(12)
    Traceback (most recent call last):
    TypeError: text must be a string

None is not a string:

    >>> text_indentation(None)
    Traceback (most recent call last):
    TypeError: text must be a string
