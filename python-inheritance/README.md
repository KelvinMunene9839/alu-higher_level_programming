# Python - Inheritance

This project introduces the core concepts of object-oriented programming in Python, especially inheritance.

## Topics covered

- Working with classes and objects
- Understanding inheritance and subclasses
- Using built-in object inspection tools like `dir()` and `isinstance()`
- Implementing custom classes such as `MyList`, `BaseGeometry`, `Rectangle`, and `Square`

## Files

- `0-lookup.py` - returns the available attributes and methods of an object
- `1-my_list.py` - a list subclass with sorted output support
- `2-is_same_class.py` - checks whether an object is exactly an instance of a class
- `3-is_kind_of_class.py` - checks whether an object is an instance of a class or its subclass
- `4-inherits_from.py` - checks whether an object inherits from a class
- `5-base_geometry.py` - empty base geometry class
- `6-base_geometry.py` - base geometry class with an area method
- `7-base_geometry.py` - base geometry class with integer validation
- `8-rectangle.py` - rectangle class using validated dimensions
- `9-rectangle.py` - rectangle class with area and string representation
- `10-square.py` - square class inheriting from rectangle
- `11-square.py` - square class with custom string output

## Requirements

- Python 3.8+
- Files should follow the project style requirements
- Each script should start with `#!/usr/bin/python3`
